# 3D Avatar Models

Place your `.glb` (GL Transmission Format Binary) avatar models in this directory.

## Recommended Models

- Use models with morph targets for facial expressions
- Recommended format: GLB with embedded textures
- Optimal polygon count: 10,000-50,000 triangles

## File Naming

```
glb/
├── student-avatar.glb      # Default student avatar
├── teacher-avatar.glb       # Teacher avatar
└── custom-avatar.glb        # Your custom avatar
```

## Notes

The `student-avatar.png` should be placed in the parent `avatars/` directory.

For more avatar models, visit:
- Ready Player Me: https://readyplayer.me/
- VRM models: https://vrm.dev/en/
