# 常见密钥格式扫描模式（grep -E 语法，每行一个）
# 命中即视为疑似密钥。新增平台 key 前缀时在此追加。
# 注意：grep -E 的 \s 在部分平台不支持，用 [ ] 兼容（此处模式用于 grep -E 时已避开 \s）

# Google / Gemini
AIza[0-9A-Za-z_\-]{30,}

# OpenAI / DeepSeek / 各大 LLM（sk- 前缀）
sk-[A-Za-z0-9]{20,}

# GitHub 令牌
ghp_[A-Za-z0-9]{20,}
gho_[A-Za-z0-9]{20,}
github_pat_[A-Za-z0-9_]{20,}

# AWS Access Key
AKIA[0-9A-Z]{16}

# JWT（三段式 eyJ...）
eyJ[A-Za-z0-9_\-]{20,}\.[A-Za-z0-9_\-]{20,}\.[A-Za-z0-9_\-]{10,}

# 通用赋值模式（忽略大小写，见脚本）：
#   (api[_-]?key|secret|passwd|password|token) = "一串字符"
